# FerreMundo

**Alumno:** Alexis Junco

## Descripción del proyecto

FerreMundo es una aplicación web de e-commerce orientada a la venta de productos de ferretería.

El proyecto cuenta con una página principal, una página de inicio de sesión, una página de registro de usuarios y diferentes categorías de productos.

### Categorías

* Ferretería
* Herramientas
* Materiales
* Seguridad

El objetivo de esta primera etapa es desarrollar la estructura general de la aplicación y permitir la navegación entre sus diferentes páginas.
